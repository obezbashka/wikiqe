# 🖥️ VLESS + Smart TV

**Вариант с флешкой:**

1. [Скачать на флешку приложение “v2rayNG”](https://github.com/2dust/v2rayNG/releases/download/1.8.35/v2rayNG_1.8.35_universal.apk) (установочный apk-файл)
2. Скопировать ключ доступа из меню управления подпиской и сгенерировать из него QR-код с помощью любого сервиса (например [code-qr.ru](https://code-qr.ru/))
3. Скопировать полученный файл с QR-кодом (изображение) на флешку
4. Установить на телевизор приложение “RS проводник”
5. Подключить флешку к телевизору, открыть приложение “RS проводник”
6. В **RS проводнике** найти подключенную флешку, установить приложение “v2rayNG” с помощью apk-файла
7. Открыть приложение “v2rayNG”, нажать на “+” в верхнем правом углу экрана и выбрать “Импорт из QR-кода”
8. Нажать на иконку изображения, в открывшемся окне выбрать “RS проводник”
9. В проводнике найти подключенную флешку, выбрать изображение с QR-кодом\


**Вариант с облачным сервисом:**

1. [Скачать приложение “v2rayNG”](https://github.com/2dust/v2rayNG/releases/download/1.8.35/v2rayNG_1.8.35_universal.apk) (установочный apk-файл)
2. Скопировать ключ доступа из меню управления подпиской и сгенерировать из него QR-код с помощью любого сервиса (например [code-qr.ru](https://code-qr.ru/))
3. Открыть облачный сервис (например Google Drive), загрузить в него apk-файл и изображение QR-кода
4. Установить на телевизор приложение “RS проводник”
5. В приложении “RS проводник” открыть облачный сервис с нужными файлами
6. Установить приложение “v2rayNG” с помощью apk-файла
7. Открыть приложение “v2rayNG”, нажать на “+” в верхнем правом углу экрана и выбрать “Импорт из QR-кода”
8. Нажать на иконку изображения, в открывшемся окне выбрать “RS проводник”
9. В “RS проводнике” найти облачный сервис, выбрать изображение с QR-кодом
